# Webtech-Exp3
Aim :
To design and develop a responsive webpage using HTML5 and CSS3 with different styling properties such as colors, fonts, margins, padding, text shadows, hyperlinks and flexible layouts.

Description:
HTML5 is used to structure the content of a webpage, while CSS3 is used to style and design it. CSS3 provides various properties to change the appearance of a webpage, including background colors, fonts, spacing, borders, text formatting and layouts.
In this experiment, a responsive webpage is created using HTML5 and an external CSS file. The webpage contains a header, navigation bar, main content section, sidebar and footer. Different CSS properties are applied to make the webpage attractive and responsive to different screen sizes.

Procedure:

1.	Open Visual Studio Code.

2.	Create a new folder named Experiment 3.

3.	Inside the folder, create two files named index.html and style.css.

4.	Open index.html and write the basic HTML5 structure.
5.	Add a header section with a heading and paragraph.

6.	Create a navigation bar with Home, Features, About and Contact links.

7.	Create a container with a main content section and sidebar.
 
8.	Add headings, paragraphs, lists and external hyperlinks.

9.	Create a footer section at the bottom of the webpage.

10.	Open style.css and apply CSS properties to the webpage.

11.	Set the background color, font family, text alignment, margins and padding.
12.	Apply text shadows, font styles, borders and background colors.

13.	Use hyperlink pseudo-classes such as :link, :visited, :hover and :active.

14.	Use Flexbox properties such as display: flex, flex-wrap and gap to arrange the content.

15.	Save both files.

16.	Open index.html in a web browser and observe the responsive webpage.
